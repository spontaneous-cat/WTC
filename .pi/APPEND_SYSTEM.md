# WTC project instructions

This repo is an Expo React Native + TypeScript Firebase companion app for the physical social-deduction game Within the Collective. Treat `docs/WTC_PROJECT_SPEC.md` as product source of truth, then read `docs/HANDOVER.md`, `docs/IMPLEMENTATION_PROGRESS.md`, and `docs/SETUP.md` before substantial work. Current state is a validated development preview: lobby/create/join/setup/start/private roles/player list/suspicions/history/settings are implemented; kills, disputes, alerts, voting, executions, win checks, runtime admin controls, results, deployment, and native device testing are not complete. Preserve privacy invariants: authoritative state in server-only Firestore docs, public/owner-only projections only, no hidden roles/deaths in broadly readable documents, admin gets no hidden role knowledge. Use Firebase emulators by default (`demo-wtc`); never create/deploy paid/cloud resources or service-account secrets without explicit user approval. Work in vertical TDD slices, keep `npm run check`, emulator/security tests, UI tests, and builds honest, and ask unresolved gameplay clarifications one at a time rather than inventing rules.
